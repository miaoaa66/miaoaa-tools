# 图片旋转

旋转图片任意角度并导出。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 用快捷按钮或任意角度滑块旋转。
3. 点击「保存到本地」。

## 参数 / 选项

- 快捷按钮：左转 90° / 右转 90° / 旋转 180°
- 任意角度滑块（-360–360）

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas（`translate`、`rotate`、`drawImage`）
- 导出格式根据原文件扩展名决定（jpg / webp / png），背景透明
