# 图片九宫格切图

将图片按 3×3 切分为 9 块，可单块或全部下载。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 选择切分模式与输出格式。
3. 点击「生成切片」。
4. 点预览单块下载或「全部下载」。

## 参数 / 选项

- 切分模式：原图等分 / 正方形居中
- 输出格式：PNG / JPEG / WebP
- JPEG 质量滑块

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas `drawImage`、`toBlob`
- 图片过小（单块小于 1px）无法切分；「全部下载」逐块间隔 300ms 触发避免被拦截
