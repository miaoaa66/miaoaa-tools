# 图片加水印

给图片添加文字水印，支持平铺或单点定位。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 输入水印文字并调整样式。
3. 实时预览。
4. 点击「保存到本地」。

## 参数 / 选项

- 水印文字（≤50 字）
- 字体大小（12–200）、颜色、透明度（0.05–1）、旋转角度（-90–90°）
- 平铺开关及水平 / 垂直间距
- 单点时位置：左上 / 右上 / 居中 / 左下 / 右下

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas `fillText`、`transform`
- 预览防抖 80ms；导出 PNG
