# 图片裁剪

上传图片后拖动 / 缩放裁剪框，按指定形状与尺寸裁剪并下载。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 拖拽或点击上传图片。
2. 拖动裁剪框移动、拖动右下角手柄缩放。
3. 设置形状 / 比例或像素。
4. 点击「下载裁剪图片」。

## 参数 / 选项

- 裁剪形状：方形 / 圆形
- 尺寸模式：宽高比例 / 像素大小
- 比例下拉：自由 / 1:1 / 4:3 / 3:4 / 16:9 / 9:16
- 像素宽高输入框

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas（`drawImage`、`clip`、`toBlob`）、`URL.createObjectURL`
- 圆形裁剪强制输出正方形 PNG；导出格式固定为 PNG
