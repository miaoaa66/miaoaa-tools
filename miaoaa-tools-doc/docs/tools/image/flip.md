# 图片水平/垂直翻转

对图片做水平或垂直镜像翻转后导出。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 开启水平 / 垂直翻转开关。
3. 点击「保存到本地」。

## 参数 / 选项

- 水平翻转开关、垂直翻转开关

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas（`translate`、`scale`）
- 未开启任何翻转时不允许下载；导出 PNG
