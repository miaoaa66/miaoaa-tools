# 图片裁剪圆角

给图片四角裁成圆角，并可填充背景色后导出。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 调整圆角大小与背景色。
3. 点击「下载圆角图片」。

## 参数 / 选项

- 圆角大小滑块 / 输入框
- 背景颜色选择器（支持 alpha）

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas（`roundRect`、`clip`、`toBlob`）
- 圆角最大值为短边的一半；导出 PNG
