# 透明图片加背景

给透明图片填充背景色，支持内边距与背景圆角后导出。

::: tip 所属分类
**图片工具**
:::

## 使用步骤

1. 上传图片。
2. 选择背景色 / 常用色。
3. 调整四向内边距与圆角。
4. 点击「保存到本地」。

## 参数 / 选项

- 背景色选择器、10 个常用色圆点
- 四向内边距输入框（0–500）
- 背景圆角滑块（0–200）
- 输出格式：PNG / JPG

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：Canvas（自定义 `roundRect`、`fill`、`toBlob`）
- JPG 输出无透明，圆角外铺背景色；导出文件名含背景色 hex
