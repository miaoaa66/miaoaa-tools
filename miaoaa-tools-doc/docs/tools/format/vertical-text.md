# 文字竖排

将文本按字符拆分为多列，以从右至左的竖排（古诗词）方式预览。

::: tip 所属分类
**格式化工具**
:::

## 使用步骤

1. 输入文本。
2. 调整每列字数、字号。
3. 查看竖排预览。
4. 可复制竖排文本（按列换行）。

## 参数 / 选项

- 每列字数（1–30，默认 7）
- 字号（14–64px，默认 36）

## 技术实现

- **依赖库**：Element Plus
- 列顺序反转显示（右 → 左）；复制结果按列用换行符连接
