# SQL 格式化

将 SQL 语句按子句换行、缩进并大写关键字。

::: tip 所属分类
**格式化工具**
:::

## 使用步骤

1. 输入 SQL 语句。
2. 选择缩进空格数。
3. 点击「格式化」。
4. 复制结果。

## 参数 / 选项

- 缩进：2 / 4 空格

## 技术实现

- **依赖库**：Element Plus
- 自研词法分析器，支持注释、字符串、子查询、`AND / OR` 换行缩进；非标准化，复杂方言可能不精确
