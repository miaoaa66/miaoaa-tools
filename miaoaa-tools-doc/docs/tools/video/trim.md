# 视频时长裁剪

上传视频后选取起止区间裁剪导出，流复制无重编码损失。

::: tip 所属分类
**视频工具**
:::

## 使用步骤

1. 上传视频。
2. 播放预览，点击时间轴跳转。
3. 用输入框 / 滑块或「设为当前」确定起止时间。
4. 点击「裁剪并下载」。

## 参数 / 选项

- 开始 / 结束时间输入框（步进 0.1s）
- 时间轴点击、设为当前按钮

## 技术实现

- **依赖库**：`mediabunny`、`@mediabunny/mp3-encoder`（`registerMp3Encoder`）
- 支持 MP4 / WebM / MOV / MKV；输出按原扩展名，不支持时降级 MP4；依赖浏览器编码能力
