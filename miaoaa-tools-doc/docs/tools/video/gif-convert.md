# 视频&GIF互转

上传视频转成 GIF 动图，或把 GIF 动图转回视频，全程在浏览器本地完成，数据不上传。

::: tip 所属分类
**视频工具**
:::

提供两个标签页：

- **视频转 GIF**：把视频的某一段抽帧编码为 GIF 动图。
- **GIF 转视频**：把 GIF 逐帧编码为 MP4（环境不支持时降级为 WebM）。

## 使用步骤（视频转 GIF）

1. 在「视频转 GIF」标签页上传视频（支持 MP4 / WebM / MOV 等格式）。
2. 设置帧率、最大宽度、起止时间等参数（见下）。
3. 点击「转换为 GIF」，等待进度条完成。
4. 预览生成的 GIF，点击「下载 GIF」保存到本地。

## 使用步骤（GIF 转视频）

1. 切换到「GIF 转视频」标签页，上传 `.gif` 动图。
2. 系统会解析帧信息并显示总帧数与尺寸。
3. 点击「转换为 MP4」，等待进度条完成。
4. 预览生成的视频，点击「下载 MP4」保存（不支持 H.264 时自动输出 WebM）。

## 参数 / 选项（视频转 GIF）

- **帧率 (fps)**：1–30，默认 10。帧率越高 GIF 越流畅但体积越大、转换越慢。
- **最大宽度**：0–4096，默认 480。0 表示保持原始宽度；非 0 时按比例缩放。
- **起始时间 / 结束时间 (s)**：精确到 0.1s，用于截取视频的某一段。
- 内置保护：单次转换最多 500 帧，超出会提示降低帧率或缩短区间。

## 技术实现

- **依赖库**：`gifenc`（GIF 编码）、`gifuct-js`（GIF 解析）、`mediabunny`（视频解码 / 编码）。
- **视频转 GIF**：使用 WebCodecs（`CanvasSink`）按时间戳全速顺序抽帧，再用 `gifenc` 量化调色板并编码，纯前端、无 ffmpeg。
- **GIF 转视频**：`gifuct-js` 解析各帧，`mediabunny` 编码为 H.264 / MP4，失败则降级为 VP9 / WebM。
- 所有处理均在本地浏览器完成，不上传任何文件。

## 浏览器兼容性

- **视频转 GIF** 依赖 WebCodecs API，需在 Chromium 内核浏览器（Chrome / Edge / 新版本 Chromium 系）中使用。
- Firefox / Safari 等未提供 WebCodecs 的环境可能无法抽帧，建议改用支持的浏览器。
