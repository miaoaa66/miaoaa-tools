# 字母大小写互转

文本转换为大写或小写。

::: tip 所属分类
**转换工具**
:::

## 使用步骤

1. 输入文本。
2. 点击「转大写」或「转小写」。
3. 复制结果。

## 参数 / 选项

无。

## 技术实现

- **依赖库**：无（`toUpperCase` / `toLowerCase`）
- **浏览器能力**：`navigator.clipboard`
