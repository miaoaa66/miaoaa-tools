# avif/webp 转 png

将 AVIF / WebP 格式图片转换为 PNG 并下载。

::: tip 所属分类
**转换工具**
:::

## 使用步骤

1. 拖拽或点击上传 `.avif` / `.webp` 图片。
2. 预览原图。
3. 点击「转换为 PNG」。
4. 点击「下载 PNG」保存。

## 参数 / 选项

无。

## 技术实现

- **依赖库**：无第三方库
- **浏览器能力**：`Image.decode`、`Canvas`、`canvas.toBlob`、`URL.createObjectURL`
