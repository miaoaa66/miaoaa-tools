# 时间戳转换

时间戳与日期时间互转，并显示当前时间。

::: tip 所属分类
**转换工具**
:::

## 使用步骤

1. 输入时间戳，点击「转换」得日期。
2. 或选择日期，点击「转换」得秒 / 毫秒时间戳。
3. 底部实时显示当前时间。

## 参数 / 选项

- 无（自动判断秒 / 毫秒：13 位及以上按毫秒）

## 技术实现

- **依赖库**：无（`Date`）
- **浏览器能力**：`navigator.clipboard`
- 当前时间每 1 秒刷新
