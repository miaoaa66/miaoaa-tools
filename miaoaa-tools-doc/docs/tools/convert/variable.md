# 变量格式转换

变量名在多种命名格式之间自动互转。

::: tip 所属分类
**转换工具**
:::

## 使用步骤

1. 输入变量名。
2. 实时自动生成 9 种格式。
3. 逐项复制所需格式。

## 参数 / 选项

- 无（输出固定 9 种：小 / 大驼峰、下划线、常量、连字符、分词等）

## 技术实现

- **依赖库**：无（正则分词）
- **浏览器能力**：`navigator.clipboard`
- 支持大小写交界、连字符、下划线等分词规则
