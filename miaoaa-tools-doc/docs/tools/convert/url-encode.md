# URL 编码/解码

URL 字符串编码与解码。

::: tip 所属分类
**转换工具**
:::

## 使用步骤

1. 选择编码方式。
2. 输入文本。
3. 点击「编码」或「解码」。
4. 复制结果。

## 参数 / 选项

- 单选：`encodeURI` / `encodeURIComponent`

## 技术实现

- **依赖库**：无（内置 `encodeURI` / `decodeURI` 系列）
- **浏览器能力**：`navigator.clipboard`
- 解码失败给出错误提示
