# 代码对比

对基准文本与多个版本做行级 + 字符级差异对比并高亮。

::: tip 所属分类
**代码工具**
:::

## 使用步骤

1. 选择栏数（2 / 3 / 4）。
2. 在各栏输入或「上传文件」文本。
3. 点击「对比」。
4. 用「首个 / 上一个 / 下一个 / 末个」导航差异。

## 参数 / 选项

- 栏数：两 / 三 / 四栏
- 第一栏为「基准」
- 可上传文件、清空、拖拽调整输入框高度

## 技术实现

- **依赖库**：Element Plus（diff 算法为原生 LCS 实现，无第三方库）
- 要求基准栏必填；统计新增 / 删除 / 差异行数
