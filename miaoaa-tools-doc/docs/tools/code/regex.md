# 正则表达式测试

测试正则匹配并展示匹配值、捕获组、命名分组，支持替换操作。

::: tip 所属分类
**代码工具**
:::

## 使用步骤

1. 输入正则（或点「常用正则」预设）与 flags。
2. 输入测试文本。
3. 点击「测试匹配」。
4. 或点击「替换」后填替换文本执行。

## 参数 / 选项

- 正则表达式、flags（默认 `g`）
- 测试文本、替换文本（留空则替换为 `($&)`）
- 内置约 50 个常用正则预设（邮箱、手机号、身份证、URL、日期等）

## 技术实现

- **依赖库**：Element Plus
- 基于原生 `RegExp`；替换面板点「替换」按钮切换显示
