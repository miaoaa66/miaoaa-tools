# miaoaa-tools   

本地离线可用的，常用开发工具   

仓库：    
https://gitee.com/miaoaa66/miaoaa-tools   


## 功能   

✅ avif/webp转png   
✅ 图片&Base64互转   
✅ 图片&SVG互转   
✅ 图片转ico   
✅ GIF拆分PNG   
✅ 多PNG合成GIF   
✅ URL编码/解码   
✅ 变量格式转换   
✅ 字符串生成二维码   
✅ 二维码解码   
✅ 字符串生成条形码   
✅ 条形码解码   
✅ 图片裁剪   
✅ 图片压缩   


## 需求 

json格式化   
代码对比   
sql格式化   
图片九宫格切图   


## node版本   

推荐使用22.16.0   
我使用这个版本运行没问题   


## 运行项目   

```
# 下载
npm i 

# 运行
npm run dev

```
